Unused Asset Detector

Purpose: Find assets that appear to have no references and identify potential candidates for removal.

Scope

This should be completely self-contained and conservative.

It should scan the project when requested rather than maintaining a permanent database.

Reference sources

Check:

* Scenes
* Prefabs
* Materials
* Animation Clips
* Animator Controllers
* ScriptableObjects
* Sprite Atlases
* Addressables
* Resources
* Build Settings
* Asset references
* Serialized Unity references

Results

Categorize assets:

Definitely Unreferenced

Potentially Unreferenced

Indirectly Referenced

Excluded

Safety features

Never immediately delete anything.

Instead:

Scan → Review → Select → Quarantine

The tool could move selected assets into a generated quarantine folder while preserving their original paths in a temporary manifest.

Then provide:

Restore

if something breaks.

Important exclusions

Allow users to explicitly exclude:

* Folders
* Asset types
* File patterns
* Addressable groups
* Resources
* Custom runtime-loading systems

This is particularly important because reflection, string-based loading, and custom slot-game asset systems can create references that Unity’s normal dependency analysis cannot see.

Deliverable

One standalone UnusedAssetDetector EditorWindow.

⸻

Recommended philosophy for all five

Since you’re deliberately keeping them isolated, I’d give each tool the same user experience philosophy, but not share implementation:

Select → Scan → Analyze → Highlight → Report

And each should:

* Have no dependency on the other tools.
* Have no shared database.
* Have no required runtime framework.
* Be installable by simply dropping its folder into the Unity project.
* Store its own preferences independently.
* Support JSON/CSV export where useful.
* Never modify project assets unless explicitly designed to do so.
* Work on demand rather than continuously scanning the project.
* Clearly distinguish measured facts from optimization recommendations.
